## What the repair changed (behavior)

- Readiness draining (a): no sleep while backlog exists; may-remain
  re-poll; idle poll 10ms → **2ms**, derived so one sleep at the
  fastest measured burst (A2b 127648/s) fits the 780-record ring
  (256 records, 3× margin) — the 10ms ceiling (78k/s) bound E-burst
  at 7813. At 2ms polling the per-tick quantum regime behind F2b
  cannot recur (≤256 records/tick ≪ 4096 quantum); re-poll remains
  as the terminal-path backstop.
- Split identities + terminal bound (b): capture/detach shares
  sampled at loop end / terminal start, always summing to the
  published counters (checker-enforced); terminal drain explicitly
  bounded (65536) with a truncation flag.
- Slow-sink policy (c), declared: **bounded-wait-drop** — each
  stdout flush waits at most 250ms/tick for writability, then drops
  its pending bytes with counters (`sink_timeouts`,
  `sink_dropped_bytes`, `sink_stall_ms`); drops gate the verdict to
  PARTIAL. Two binding fixes the envelope runs forced: the fd is
  nonblocking (a blocking write past a poll-ready page trickled
  28.7s), zero remaining budget drops instead of
  poll(0)-and-continue, and the sink wraps a dup'd raw fd
  (`stdout_sink()`, pinned unbuffered — `StdoutLock`'s LineWriter
  parked bytes past the poll loop and its EAGAIN killed the
  observer). The `-o` file stream never drops.
- Drain-path scheduling (d): UI render + aggregate-map reads on
  slower frame schedules; discovery frame-gated + shallow (ring
  drained every frame regardless — shallow skips only idle batch
  work, never ring data); first forced full sweep deferred past
  attach (frame 1 → frame 5: attach just swept, frame 1's cold
  re-sweep blocked 2.5s every run).
- Buffered trace writes (e): 64KiB batches; E-trace stays 0.
- Instruments: `SchedulingEvidence` (splits, budgets, sink,
  phase_ms + `discovery_terminal`, capture-only
  `max_inter_drain_gap_ms` frozen at loop end), stderr cancel
  marker, harness `check_scheduling_evidence` /
  `attribute_loss` (bounds: drain-tick-budget, detach-window,
  terminal-drain-bound, slow-sink, ring-capacity-vs-production;
  UNATTRIBUTED never silent) / 100ms `cancel_probe_verdict`.

## Cancellation measurements

Stock harness + external SIGINT to the observer mid-burst at an
operator-recorded monotonic send time (post-processed into
`meta.json` `cancel_probe.sent_mono_ns`; originals kept as
`*.orig.json` / `*.precancel.*`). Marker fires at loop exit,
before detach work: 68.2ms and 70.4ms (budget 100ms), both
`pass: true` in-record. The 60ms/link detach floor sits after the
marker (worked around, not through). Detach itself is 7.7s pid /
55–58s system — undrained by design, counted per-phase per 1(b).
