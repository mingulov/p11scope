# Security

Report a suspected vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/mingulov/p11scope/security/advisories/new)
for `mingulov/p11scope`. Do not open a public issue for it.

No supported-version window is published yet; report against the newest
release. Include the version (`p11scope --version`), the
`p11scope doctor` output, and steps to reproduce.
