# Task 2.2: multi-attach measurements (mixed loading + regrouped attach)

**Date:** 2026-09-20 · **Branch:** `task-2.2/multi-attach` · **Rev:** `48d663c`
**Kernel:** `7.0.0-31-generic` (x86_64) · **Toolchain:** Rust 1.88 (release build)
**Cell:** `/var/tmp/p11scope-ws-tmp/task-2.2-measure` (0700, sticky parents)

## Method

E2E-shaped lane mirroring `scripts/verify-attach-e2e.sh` (`/tmp/task22_lane.sh`,
kept out of the repo per scratch rules):

- Workload: `spike/harness.c` (built `-O0`) against SoftHSM2 with a private
  token store; deterministic 226-call ground truth in `spike/expected.txt`.
  The harness blocks on a go-file until the observer prints its first live
  frame, so every PKCS#11 call happens after the probes are on.
- Observer: release `p11scope profile --attach-backend <multi|singles|auto>
  --pid <WPID> --mode metrics --duration 20 -o <lane>.json`, under
  `strace -f -T -e trace=bpf,perf_event_open` for link/open counts + time.
- Signals per run: `/proc/loadavg`, spawn→first-frame wall time, observer
  max fds (3 samples mid-capture; the real p11scope pid, not the sudo/strace
  wrappers), `attached_probes`/`attach_failures`/detach phase ms/completeness
  from evidence JSON, per-slot call counts, `BPF_LINK_CREATE` split by attach
  type with summed `-T` time, `perf_event_open` count + summed time.
- Oracle: `check-capture-evidence.py clean-metrics <lane>.json spike/expected.txt`
  per metrics run; profile-mode runs additionally assert the rendered
  `attach_mechanisms` against the oracle rule
  (`mechanisms == sorted(set)`, subset of `{"per-offset","uprobe-multi"}`,
  nonempty iff attached>0).

Caveats: the box was noisy (loadavg 5–10, parallel workers), so `-T` sums
include deschedule time and wall times are approximate; link/open COUNTS and
fd counts are exact. `strace` overhead applies equally to both backends.

## Per-run argv

All runs: `p11scope profile --attach-backend <BACKEND> --pid <WPID> --mode
<MODE> --duration 20 -o /var/tmp/p11scope-ws-tmp/task-2.2-measure/<LANE>.json`
with `<BACKEND>/<LANE>` per row below (`-rN` = rep N). Rev `48d663c` throughout.
