# v0.8.0 Key Metadata Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship inferred key family, size class, and source-carrying creation facts on per-key rows, plus provider/token/mechanism info (Task 7).

**Architecture:** Port the R2 creation-template path with per-field source (v6); add S-cell/V-scalar length evidence and info evidence as evidence-only trailers on already-probed endpoints (separate `EVIDENCE_POSITIONS` table — `object_descriptor()` untouched, journal classification/census/sole-complete/alias agreement byte-identical, +0 endpoints, 384/496/624-byte forms); join completion lengths to operation identity in userspace (no `AggKey` dimension, no `metadata_at_use` rewrite, corroboration slot for retained completions, U1 parking for rowless keys); publish closed v7 row keys with concise text and `-v` detail; capture fixed-size provider/token/mechanism fields at return on CKR_OK (Task 7, 496-byte form + schema section, default inventory and CBOM).

**Tech Stack:** Rust (edition 2024, release toolchain `.release-rust-version`), existing object-capture adapters; no new crates, no new maps.

**Spec:** `docs/superpowers/specs/2026-11-14-v080-keymeta-design.md`
(round 6: evidence-only trailers, `secret`/`xeddsa` families, §4.5
compat table, (mechanism subset, evidence kind, length) triples,
disjointness guard, corroboration slot, R2 block in Task 0,
per-field `source` in v6, PIN policy published, repeat rule,

## Global Constraints

- Never capture PINs/keys/payloads/env; `docs/privacy/allowlist-v1.md` byte-identical.
- Missing observations stay unknown with named reasons; refusals, loss and PARTIAL coverage reported honestly.
- No BPF change before the applicable amendment text passes owner/Opus privacy review + Codex re-review (§11 + R2 block for Tasks 1–4, §17.3 for Task 7 — each still PROPOSED until then).
- `metadata_at_use` stays established-only and frozen at Init receipt; no-backfill pins re-run green.
- Journal classification, the `[0,19,79,6]` census, the sole-complete 20, alias agreement, the v1 tail and its validator stay byte-identical (non-interference twins in Task 2).
- Profile, trace and metrics never carry object facts; observed-profile v2/v3 untouched.
- Schema section versions: v6 = R2 + per-field source, v7 = inferred keys, Task 7 section = next free (suggest v8); older versions frozen and byte-stable.
- Concise CLI default; inferred facts parenthetical only where they add information; `-v`/JSON carry detail.
- Cargo only via `mise exec -- ./scripts/cargo.sh`; TMPDIR on disk, umask 022.
- Tests-first: RED run saved outside tracked files, then GREEN; every new check non-vacuous.

## Review Focus

- A length cell aliasing payload bytes must refuse via span guards, never publish a payload-derived class — pinned by disjointness twins in Task 2.
- A cell above the buffer (NSS/pkcs11-provider layout) must be accepted — pinned by the above-buffer twin in Task 2.
- A 2041-bit RSA key (256-byte signature) must show "RSA 2048 (from signature length)" with `size_class: 2048` + `modulus_bytes: 256`, never `rsa_2048` in `metadata_at_use` — pinned by the 2041 control in Task 3.
- A key used under two specific mechanism families must show `conflicting` with both sides, never first-wins — pinned by conflict twins in Task 3; `secret` beside any family and compatible §4.5 pairs never conflict.
- A query/too_small/terminal triple must yield exactly one completion — pinned by the over-estimate twin in Task 3.
- Inferred facts must never reach CBOM `related-crypto-material` established fields — pinned by a CBOM exclusion twin in Task 3.
- A provider with NULL `C_SignRecover` must still admit no-manifest key operations (no entry gating change) — pinned by an authority twin in Task 2.
- A provider returning sentinel serial/label/session/memory/clock/pad bytes must publish none of them anywhere — pinned by the Task 7 sentinel + CBOM twins; PIN-state bits and PIN lens publish exactly.
